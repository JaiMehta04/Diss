# Data Directory

This directory contains input data files for the project.

## Files

| File | Description | Source |
|------|-------------|--------|
| `combined_station_data.csv` | Raw CPCB water quality measurements (75,801 rows) | CPCB ENVIS Portal |
| `combined_station_data_with_coords.csv` | Measurements enriched with station coordinates | Generated by preprocessing scripts |
| `cpcb_station_locations.csv` | CPCB station registry with coordinates | CPCB |

## Obtaining the Data

1. **CPCB measurements**: Download from [CPCB ENVIS Portal](https://cpcbenvis.nic.in/)
2. **Station locations**: Available from CPCB station database
3. **Satellite data**: Extracted automatically via Google Earth Engine (see `src/data_collection/`)

## Generated Data (not in Git)

Large generated datasets are excluded from version control:

- `GangaIndices_All/satellite_indices.csv` — Sentinel-2 features per station-day
- `GangaIndices_All/merged_bn_dataset.csv` — Merged training dataset
- `SentinelPatches/*.npy` — 64×64 image patches (~2GB)
