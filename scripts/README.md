# Utility Scripts

Helper scripts used during the research process. These are **not** part of the main pipeline but were used for specific tasks during development.

| Script | Purpose |
|--------|---------|
| `extract_nwmp_pdfs.py` | Extract tables from NWMP annual report PDFs |
| `parse_nwmp_html.py` | Parse NWMP HTML data pages |
| `download_nwdp_cpcb.py` | Download data from NWDP/CPCB portal |
| `extract_narmada_data.py` | Extract Narmada river data (for generalization testing) |
| `extract_tapi_data.py` | Extract Tapi river data (for generalization testing) |
| `assemble_and_integrate.py` | Early version of data assembly |
| `generate_ieee_paper.py` | Auto-generate IEEE paper LaTeX draft |
| `generate_presentation.py` | Generate PowerPoint presentation |
| `generate_research_paper.py` | Generate research paper draft |
| `dashboard.py` | Interactive data exploration dashboard |
| `check_progress.py` | Print pipeline progress summary |
